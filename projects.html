My Projects

A collection of responsive and interactive web projects built with HTML, CSS, and JavaScript.

Creatures — JavaScript Data Attributes

This project demonstrates how JavaScript can use custom data attributes to organize and filter content. I used HTML data attributes to categorize creatures by type and habitat, then used querySelectorAll() and NodeLists to select groups of elements and dynamically update their styles when the user interacts with the buttons.

Live Demo GitHub Repo

Coffee and daily-Grind JavaScript Coffee App

This single-page application displays dynamic daily content using JavaScript's Date object to detect the current day of the week. A switch statement updates the featured coffee, color scheme, image, and descriptive information. The project also uses URL query parameters to allow users to manually select a different day's coffee.

Live Demo GitHub Repo

Puppy's Life — CSS & JavaScript

Poppy’s webpage was created as an interactive web development project using HTML, CSS, and JavaScript. HTML was used to build the structure of the website, including Poppy’s profile, photographs, favorites, gallery, chat area, buttons, and special surprise sections. CSS was then used to create the visual design, including colors, typography, spacing, layouts, cards, buttons, chat bubbles, and responsive elements. The goal was to create a webpage that was not only functional but also visually appealing and enjoyable to explore.

Bill's Advice: Take time to explain clearly and perfectly what's going on, how things work, what you've learned, and try to do so succinctly. When employers see what we've internalized, they imagine we can act as a valuable resource to them. We are selling our skills as a resource and asset, and the better job we do articulating this, the more easily an employer can see our value.

It may be MORE important to be able to clearly explain things over actually knowing them! At least if I can explain myself, I'm showing I can adapt in a dynamic manner, and if I know things but can't explain myself, no one will know what I can do.
